# Roblox Game: Snack Blockers

A Roblox game where players can place cute 3D units to block snacks from entering a mini fridge. This game is designed for players who enjoy strategy and puzzle-solving, offering a unique twist on the classic "block the path" genre.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Click on "File" in the top menu and select "Open Model".
4. Navigate to the downloaded project files and select the `.rbxl` or `.rbxlx` file.
5. Click "Open" to import the project into Roblox Studio.

## Use

1. Place the 3D units in the game world to block the path of the snacks.
2. Use the mini fridge to store the snacks.
3. The game will automatically check if the path is blocked and allow or block the snacks accordingly.
